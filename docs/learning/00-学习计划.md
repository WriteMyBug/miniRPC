# MiniRPC 学习计划（20 小时版）

> 适用对象：大四计算机应届生，目标 C++/后端校招面试。
> 前提：已有 C++ 基础（智能指针、lambda、std::thread/mutex/条件变量），学过操作系统与计算机网络。
> 学习对象：本仓库 MiniRPC（约 4900 行，四个里程碑已完成）。

## 一、学习目标（学完要达到）

| 层级 | 目标 | 验收方式 |
|---|---|---|
| L1 全链路 | 不看代码能画出并讲清一次 RPC 调用的完整流程（客户端 → 通道 → 协议 → 服务端 → 线程池 → Service → 回包） | 验收作业 1 |
| L2 模块细节 | 每个模块能独立讲 5 分钟，并能回答"为什么这么设计" | 验收作业 6（面试自测） |
| L3 动手能力 | 能独立改代码：加方法、改协议字段、调参数并验证 | 验收作业 2/3/4 |
| L4 数据意识 | 能解释压测数字：峰值并发、线程数选择、瓶颈位置 | 验收作业 5 |

一句话目标：**面试官问任何一个模块，你能讲清楚它是什么、为什么、怎么实现，并当场改得动。**

## 二、大纲

```text
阶段 0  启动与环境（0.5h）     跑通 demo，建立"全链路地图"
阶段 1  网络层（6h）           EventLoop / EpollPoller / Channel / Buffer / TcpServer / TcpConnection
阶段 2  线程池（2.5h）         任务队列 / 条件变量 / future / 回调模式
阶段 3  协议与 Codec（2.5h）   24 字节协议头 / 信封 / 粘包半包
阶段 4  RPC 核心（5h）         ServiceRegistry / RpcServer / RpcChannel / RpcController / 超时重试
阶段 5  注册中心与负载均衡（2.5h） 心跳剔除 / 轮询 / 一致性哈希 / 故障转移
阶段 6  复习与验收（1h）       自测 + 模拟面试 + 验收作业
```

合计 **20 小时**。建议节奏：**10 天 × 每天 2 小时**；冲刺模式 **5 天 × 每天 4 小时**（白天 2 段）。

## 四、学习方法（重要）

1. **先跑通，再读码**：每个阶段先运行对应示例，建立"现象"，再进代码找"原因"。
2. **读码顺序**：入口（main/示例）→ 关键类（本阶段主题）→ 细节函数。不要从头文件第一行读到最后一行。
3. **只读一遍=没读**：每个模块要求你用自己的话输出一遍（画图、写笔记、讲给自己听）。
4. **动手优先**：20 小时里至少 6 小时是动手（改代码、跑测试、做实验），不是阅读。
5. **对照资料**：架构设计决策见 [../decisions.md](../decisions.md)，面试问题答案见 [../interview-qa.md](../interview-qa.md)，但先自己答再看答案。
